Revecast — PSA Portal

Revecast PSA Portal Give your customers and external team members a branded, self-service Experience Cloud portal into their own projects, schedules, and time — no full Salesforce license required.

Revecast Product Managed Package + Site Kit Beta

What is the PSA Portal?

The PSA Portal is a ready-made Experience Cloud site that puts each external user's own Revecast PSA data in front of them — the projects they're on, their schedule, their time entries, key documents, day-off requests and more — accessed with a Customer Community Plus license instead of a full Salesforce seat. Everything a user sees is scoped to their linked Contact, so no one browses anyone else's records.

Because a live Experience Cloud site can't be delivered inside a managed package, the Portal ships in two halves: an upgradeable managed package (the Apex, Lightning Web Components, permission sets and the setup wizard) and a per-org site deploy kit (the LWR site itself, navigation, audiences and sharing). The bundled Portal Setup wizard stitches the two together in a few clicks.

Key Capabilities

Self-Service Record Pages

Out-of-the-box pages for a user's projects, project members, schedules, time entries, workstreams, key documents, day-off and more — each pre-scoped to the signed-in user's own Contact.

One-Click Provisioning

The Portal Setup wizard creates the site, deploys the site bundle, publishes it, and seeds the configurable related lists, record banners and activity timelines — turning a multi-day Experience Cloud build into a guided sequence.

Role-Based Navigation

The User Assignment tab lets an admin pick portal users and assign a role — Standard, Manager, Reviewer, or both — which in one action grants the matching permission set(s) and stamps the audience field that drives which navigation each user sees.

Configurable Components

Related lists, highlight banners and activity timelines are all driven by configuration records (from Revecast Experience Components), so what shows on each object's page is admin-tunable — no code, no Flow.

Day-Off & Time Entry

External team members can submit day-off requests and log time from the portal, flowing straight into the same Revecast PSA schedule and forecast the internal team uses.

Secure by Design

Every page self-scopes to the running user's Contact; field-level security is enforced on the data the portal returns; and the portal permission sets ship pre-branded and least-privilege.

How It Works

For admins:

  1. Install Revecast PSA (PSACore), Revecast Experience Components, then the Revecast PSA Portal package.
  2. Enable Digital Experiences and register a domain, then open the Portal Setup tab and run the wizard — it provisions the site, deploys the bundle, publishes it, and seeds the page configuration.
  3. On each portal Contact, click Enable Customer User (using the PSA Portal Community Plus User profile) to create their login.
  4. Open the wizard's User Assignment tab, select your new users, and assign a role — one click sets their permission set(s) and the navigation they'll see.

For users: log in to the portal and see your own projects, schedule, time and documents — submit a day off or log time without ever touching the internal Salesforce org.

Status

The PSA Portal is in beta as a second-generation managed package (namespace Revecast), delivered alongside a per-org site deploy kit. It depends on Revecast PSA (PSACore) and Revecast Experience Components. Data access is self-scoped and field-level-security enforced, and the release is validated by an Apex test suite plus a browser regression scenario for the user-assignment flow.
