Revecast — Reporting Engine

Revecast Reporting Engine One-click, record-scoped reports on any Salesforce object — configured by admins in minutes, no code, no Flow.

Revecast Product Managed Package Beta

What is the Reporting Engine?

The Reporting Engine puts the right reports on the right record pages, with the record's context already applied. Drop the Report Engine component on any object's Lightning record page and users get a curated list of reports that open pre-filtered to the record they're looking at — a project's revenue breakdown, an account's open work, a campaign's pipeline — one click, no hunting through report folders, no manually re-filtering.

Admins configure everything through a guided wizard inside the dedicated Report Engine app: search the org's reports, pick one, pick the object, done. The engine handles the URL construction, record-context filtering, and an optional inline panel where users can adjust filter values before opening.

Key Capabilities

Record-Context Reports

Every report opens scoped to the record it was launched from. The engine pins the record Id into the report's first filter and can map additional filters to any field on the record, a placeholder, or a literal.

Guided Template Wizard

Create or edit a report template in four steps. The wizard searches your reports, shows which dashboards use them, infers the right object from the report's type, and warns if a report can't actually receive a record filter.

Built-In Diagnostics

Every template record carries a setup panel running eight health checks — from "does the linked report still exist?" to "is the component actually placed on a page?" — each with a one-click fix and a test button that opens the real report against a sample record.

Self-Service Health

The app home page flags templates whose reports were deleted or recreated, searches and filters the catalog of templates, and shows folder and report-type context at a glance.

Inline Filter Overrides

Templates can expose their filters to users for one-off adjustments — while the record-context filter stays locked unless an admin explicitly allows overriding it.

One-Click Access Control

Two permission sets ship in the box (User and Admin), assignable to yourself or teammates straight from the app home page — no Setup trip.

How It Works

For admins:

  1. Install the package and assign yourself the Report Engine Admin permission set.
  2. Open the Report Engine app → New Template → follow the wizard (pick a report, pick the object, name it).
  3. Add the Report Engine component to that object's record page in the Lightning App Builder — the diagnostics panel confirms placement.
  4. Assign Report Engine User to everyone who should see the reports.

For users: open a record, see its reports, click one. The report opens in a new tab already filtered to that record.

Status

The Reporting Engine is in beta as a second-generation managed package (namespace Revecast). The original Flow-based implementation has been fully converted to Apex + Lightning Web Components, hardened for the AppExchange security model (user-mode data access throughout), and validated with a 50-test suite against fresh orgs.
